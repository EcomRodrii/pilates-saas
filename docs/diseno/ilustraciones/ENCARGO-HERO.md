# Imágenes grandes del panel (las «de Shopify»)

Son las que van en la tarjeta de bienvenida de cada módulo vacío: título y botón a la izquierda, imagen a la derecha.

## Cómo hacerlas (igual para todas)

| | |
|---|---|
| Formato | **PNG o WebP con fondo transparente** |
| Tamaño | **1600 × 1200 px** (4:3) |
| Encuadre | Objeto centrado, un 8 % de aire alrededor, sombra suave debajo |
| Fondo | Transparente. Como mucho, un resplandor de color muy suave detrás del objeto |
| Prohibido | Texto, números, logotipos, marcas de otros (tampoco la de Shopify) y caras detalladas |
| Colores | turquesa `#4C9CB0`, magenta `#B4537E`, arena `#ECE6DC`, blanco y tinta `#222A33` |
| Nombre | El de la tabla, exacto |

Genera primero **una**, y usa esa misma como referencia de estilo para las demás (misma luz y mismo ángulo).

### Texto base para el generador

> Render 3D de producto, estilo suave y mate, vista de tres cuartos ligeramente elevada, luz de estudio suave desde
> arriba a la izquierda, sombra de contacto difusa, fondo transparente, colores turquesa #4C9CB0, magenta #B4537E,
> arena y blanco, sin texto, sin logotipos, sin personas, composición centrada. Objetos: **[la columna «Qué se ve»]**
